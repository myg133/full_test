| D1 | 2026-11-11 | **方法使用从"声明"变成"可核验的事实"** —— `methods_applied[]` 是字符串列表，改一下就能声称用了方法。本 REQ 让"用了 M0.2"必须能在**用例集本身**里找到对应产出 | 字段层面已经脚本化（REQ-002A），但**语义层面**的方法使用还没脚本化：把 `["M0.1"]` 改成 `["M0.1","M0.2"]` 不需要任何真实产出。这是"字段齐备"的更深一层漏洞 | 否 | AC-003/004/003b |

| D4 | 2026-11-11 | 方法库与说明文档**双轨，但以 JSON 为准** —— 散文保留（帮助理解），但**校验依据只有 JSON**；两者不一致时以 JSON 为准并报错 | 散文给人读，JSON 给机器读，机器不能读散文 | 是 | AC-002 |
