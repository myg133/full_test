## §4 门 + D65 自测（BA 自己做的）

### 4.1 门的构造

- 夹具（§0.1 / §0.5 / §0.6）：**形态合法**的项目根、**形态不合法**的 run_dir、**全无敏感串**的负控产物；
  期望值（sha256 / 字节数 / 计数）**由夹具现算**，不写死臆测值；
- 指纹实现**独立**（不 import 被验包）；
- 变异注入用**入口脚本包装（shim）**（沿用 REQ-010）：原实现 move 到 `make-report.real.mjs`，
  包装调原实现后对**产物**做一处语义篡改 ⇒ 对任意实现都成立（Dev 实现之前字面量不存在）；
- 变异检出走**新增失败键**（变异失败键 − 基线失败键，**只取判据号**）；不用对称差；
- 负控 **M0**（顶层加一个无害字段）必须**未检出** ⇒ 探测器不是恒真。
